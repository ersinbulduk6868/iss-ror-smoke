# ISS Blender Battle Backend

This repository is the zero-cost validation runner for the Infinite Shorts Studio Generation Service / Battle Executor Blender backend.

Active engine candidate: Blender 4.5.13 LTS.

Scope:
- headless Blender startup on GitHub Actions
- one continuous rigid-body world
- real cross-actor collision smoke
- deterministic frame/video rendering
- machine-readable acceptance evidence

This repository contains no active Rigs of Rods runtime or workflow. Historical RoR evidence remains in git history only.

A smoke PASS is not production Battle Executor acceptance. Production acceptance still requires the full ISS contract: real production assets, Story event execution, visible impact-correlated damage, persistent damage/debris/positions, continuous world state, and final rendered video evidence.
